# 🎬 Настройка фильмотеки

## Шаг 1: Получение API ключа от TMDB

1. Перейди на сайт [The Movie Database](https://www.themoviedb.org/)
2. Зарегистрируйся (бесплатно) или войди в аккаунт
3. Перейди в **Настройки аккаунта** → **API**
4. Нажми **Request API Key**
5. Выбери **Developer** (для личного использования)
6. Заполни форму и получи API ключ

### Как заполнить форму:

**1. Название приложения (Application Name):**
- Можешь оставить "JuniorCodeSKO" или написать свое название
- Например: "My Movie App" или "Фильмотека"

**2. Адрес приложения (Application URL):** ⚠️ **ВАЖНО!**
- Нужно указать **реальный URL**, не `https://www.domain.com`
- Если у тебя нет сайта, используй один из вариантов:
  - `http://localhost:3000` (для разработки)
  - `https://github.com/твой-username/твой-репозиторий` (если проект на GitHub)
  - `https://expo.dev/@твой-username/твой-проект` (если используешь Expo)
  - Или любой другой реальный URL

**3. Тип использования (Type of Use):**
- Выбери **"Education"** (для обучения) - это подходит для учебного проекта
- Или **"Personal"** (личное использование)

**4. Сводка приложения (Application Summary):** ⚠️ **ОБЯЗАТЕЛЬНО!**
- Опиши, что делает твое приложение
- Пример на русском:
  ```
  Мобильное приложение для просмотра информации о фильмах и сериалах. 
  Показывает популярные фильмы, позволяет искать по названию, 
  отображает детальную информацию, рейтинги, актеров и трейлеры. 
  Создано для обучения React Native.
  ```
- Или на английском:
  ```
  Mobile application for viewing information about movies and TV shows. 
  Shows popular movies, allows searching by title, displays detailed information, 
  ratings, actors and trailers. Created for learning React Native.
  ```

**5. Контактная информация (Contact Info):**
- **Имя (First Name):** Твое имя (обязательно)
- **Фамилия (Last Name):** Твоя фамилия
- **Email:** Твой email (уже заполнен: mpo_gtk@mail.ru)
- **Номер телефона:** Можешь указать или оставить пустым
- **Адрес:** Можешь указать примерный адрес или оставить пустым
- **Страна:** Уже выбрана "Казахстан" ✅

**6. Чекбокс согласия:**
- ✅ Поставь галочку "I understand and agree to the Terms of Use..."

**7. Нажми "Subscribe"**

## Шаг 2: Установка API ключа

Открой файл `store/moviesStore.js` и найди строку:

```javascript
const TMDB_API_KEY = 'YOUR_API_KEY';
```

Замени `'YOUR_API_KEY'` на свой API ключ:

```javascript
const TMDB_API_KEY = 'твой_ключ_здесь';
```

## Шаг 3: Запуск приложения

```bash
npm start
```

## Готово! 🎉

Теперь фильмотека будет работать с реальными данными о фильмах и сериалах!

---

## Что делать, если не работает?

1. **Проверь API ключ** - убедись, что ключ скопирован правильно (без пробелов)
2. **Проверь интернет** - нужен доступ к api.themoviedb.org
3. **Проверь консоль** - там могут быть ошибки, которые подскажут проблему
