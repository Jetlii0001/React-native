# ⚡ Быстрый старт

## Для тех, кто хочет сразу запустить проект

### Шаг 1: Установка зависимостей

```bash
npm install
```

### Шаг 2: Запуск

```bash
npm start
```

### Шаг 3: Открыть на телефоне

1. Установи **Expo Go** на телефон
2. Отсканируй QR-код из терминала
3. Готово! 🎉
