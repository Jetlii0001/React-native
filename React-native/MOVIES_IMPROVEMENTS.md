# 🎬 100 предложений по доработке фильмотеки

2. **Hero секция** - большой баннер с популярным фильмом недели
3. **Категории с иконками** - "Популярные", "Топ рейтинга", "Скоро выйдут" с эмодзи

5. **Скелетон загрузки** - анимированные плейсхолдеры вместо ActivityIndicator

9. **Glassmorphism эффект** - размытые карточки с прозрачностью
10. **Анимированные иконки** - Lottie анимации для загрузки и пустых состояний

19. **Индикатор "Новинка"** - бейдж для недавно вышедших фильмов

## 🎨 ПРИМЕРЫ РЕДИЗАЙНА

### Цветовая схема
- **Темная тема:** #0a0a0a (фон), #1a1a1a (карточки), #6200ee (акцент)
- **Светлая тема:** #f5f5f5 (фон), #ffffff (карточки), #6200ee (акцент)
- **Градиенты:** От фиолетового к розовому для акцентов

### Типографика
- **Заголовки:** Bold, 24-32px
- **Текст:** Regular, 14-16px
- **Мелкий текст:** Light, 12px

### Компоненты
- **Карточки:** Скругление 16px, тень с размытием
- **Кнопки:** Скругление 12px, градиентный фон
- **Иконки:** 24px, с анимацией при нажатии
