Это масштабный учебный комплекс, который объясняет каждую деталь: от первых экранов до полноценной фильмотеки с максимальной информативностью.

✅ Заглушка

Чистая база для обучения: экраны, навигация, состояние, API.

✅ Фильмотека

Пром‑уровень: тренды, актеры, трейлеры, отзывы, рекомендации.

✅ UI/UX

Современный дизайн с секциями, каруселями, Hero‑блоком и анимациями.

Что делать, если установка не проходит

Проверь версию Node.js, переустанови зависимости и убедись, что терминал видит команды node и npm.

node --version
npm --version
expo --version

Экраны и навигация

В заглушке мы учимся экранным переходам, а в фильмотеке используем динамические роуты.

router.push('/movies/123?type=movie')

Состояние и Zustand

const { count, increment } = useCounterStore();

Zustand дает простое управление глобальными состояниями без Redux.

API и запросы

Мы используем TMDB и формируем полноценные данные: актеры, трейлеры, отзывы.

const data = await fetch('/movie/550?append_to_response=credits,videos')

Главная собирается из секций: тренды, топ‑рейтинг, новинки, сериалы, подборки и AI‑рекомендации.
